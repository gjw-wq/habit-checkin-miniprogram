# 每日打卡 - 习惯养成微信小程序

一个原生开发的习惯打卡小程序：创建打卡项目、设定目标天数，每天打卡一次（可附备注），用日历和统计见证你的坚持。零依赖、数据保存在手机本地。

## 功能清单

- 首页
  - 打卡项目卡片列表：项目名称、目标天数
  - 今日状态：已打卡绿色勾 / 未打卡灰色圆圈
  - 连续打卡天数、总打卡天数、进度条（已打卡 / 目标）
  - 卡片上的打卡按钮（未打卡绿色可点，已打卡置灰防重复）
  - 打卡时可输入备注；打卡成功提示并刷新
  - 添加项目按钮；点击卡片进入详情页
  - 下拉刷新；无项目时展示空状态
- 添加项目页
  - 项目名称（必填 1-20 字）
  - 目标天数（正整数，默认 21 天）
- 项目详情页
  - 项目信息卡片：名称、目标、已打卡天数、连续天数
  - 统计卡片：总天数、连续天数、完成率、最长连续打卡
  - 自实现日历（Grid 每行 7 天）：打卡日期绿色背景、今天蓝色边框、可切换上/下月、点击打卡日期查看备注、未来日期置灰
  - 打卡记录倒序列表（日期 + 备注）
  - 右上角删除项目（二次确认，连带清除该项目全部记录）
- 数据层
  - utils/storage.js：saveProject / getProjects / deleteProject / saveCheckin（防重复）/ getRecordsByProject / hasChecked
  - utils/stats.js：连续天数（从今天往前逐日检查）、最长连续、完成率
  - utils/date.js：日期格式化与月历工具

## 如何用微信开发者工具导入运行

1. 打开微信开发者工具（Windows 版），点击"导入项目"。
2. 目录选择本项目的 `02-habit-checkin-miniprogram` 文件夹（含 app.json 的那一层）。
3. AppID 选择"测试号"（project.config.json 已配置 touristappid，无需真实 AppID）。
4. 后端服务选择"不使用云服务"，点击"导入"。
5. 开发者工具自动编译后，模拟器中即可体验完整功能。
6. 真机预览：点击工具栏"预览"，用微信扫码。

## 注意事项

- 所有数据保存在微信本地 Storage，清除小程序数据会导致打卡记录丢失。
- 每个项目每天只能打卡一次，重复点击会被拦截提示。
- 连续天数规则：今天已打卡则从今天往前计算；今天尚未打卡则从昨天起算（不会因为你还没打卡就把连续清零）。
- 完成率 = 已打卡天数 / 目标天数，超过目标后进度条封顶展示。
- 删除项目会同时删除该项目全部打卡记录，操作前请确认弹窗提示。
- 如需正式上线，需在微信公众平台注册小程序账号替换 appid，并完成小程序备案与代码审核。
